# TALLER DE SEGURIDAD INFORMÁTICA: SIMULACIÓN DE PHISHING
## Documentación Completa

⚠️ **ADVERTENCIA IMPORTANTE**: Este es un taller educativo con simulación controlada de ataques de phishing. Todas las demostraciones son autorizadas y se realizan en un ambiente controlado únicamente para fines de capacitación.

---

## 📋 INFORMACIÓN GENERAL DEL TALLER

### Objetivo Principal
Capacitar a los participantes sobre los riesgos de phishing mediante una experiencia práctica y segura, permitiéndoles reconocer y responder adecuadamente a intentos de fraude electrónico.

### Objetivos Específicos
- ✅ Identificar características de emails de phishing
- ✅ Reconocer técnicas de ingeniería social
- ✅ Validar dominios y URLs antes de hacer clic
- ✅ Verificar identidad de remitentes
- ✅ Reportar sospechas de phishing
- ✅ Implementar medidas preventivas

### Duración
- 2 horas por grupo
- 5 grupos de 20 personas
- Total: 10 horas de capacitación

## 🎯 ESTRUCTURA DEL TALLER (120 minutos)

### Módulo 1: Introducción (15 minutos)
1. Bienvenida y presentación de objetivos
2. Explicación del contexto de phishing
3. Estadísticas de ataques en Argentina
4. Impacto en organizaciones

### Módulo 2: Teoría de Phishing (20 minutos)
1. ¿Qué es phishing?
2. Tipos de phishing
3. Técnicas comunes
4. Vectores de ataque

### Módulo 3: Demostración Práctica - Parte 1 (25 minutos)
1. **En vivo**: Envío de emails de phishing
2. Mostrar cómo llegan a las bandejas
3. Análisis de características sospechosas
4. Reacción de participantes (observar sin clicar)

### Módulo 4: Guía de Detección (20 minutos)
1. Análisis detallado de emails recibidos
2. Explicación de indicadores
3. Técnicas de validación
4. Herramientas disponibles

### Módulo 5: Demostración Práctica - Parte 2 (25 minutos)
1. **Voluntarios**: Intentan acceder a página fake
2. Mostrar cómo se vería un sitio de phishing
3. Captura de pantalla (SIN datos reales)
4. Análisis de URL y certificados SSL

### Módulo 6: Mejores Prácticas y Cierre (15 minutos)
1. Checklist de protección
2. Procedimientos de reporte
3. Preguntas y respuestas
4. Evaluación de aprendizaje

## ⚡ CONFIGURACIÓN TÉCNICA PARA LA NOTEBOOK

```
1. Crear 5 cuentas de Gmail/Outlook (una por grupo)
   - Ejemplo: taller.grupo1@gmail.com
2. Anotar credenciales en lugar seguro
3. Configurar filtros para no perder mensajes
4. Probar recepción de emails antes del taller
```

### Paso 2: Preparar Página de Login Falsa
```
1. Descargar archivo HTML: fake-login-page.html
2. Abrir sin servidor (simplemente con navegador local)
3. Probar que se vea correctamente
4. Tener captura de pantalla lista
5. IMPORTANTE: NO conectar a internet durante demo
```

### Paso 3: Preparar Presentación
```
1. Tener todas las plantillas de phishing impresas
2. Tener checklist visible
3. Preparar ejemplos de URLs falsas
4. Tener guía de detección a mano
```

## 🎬 GUIÓN PARA LA DEMOSTRACIÓN VIVA

### Antes de Enviar (Comunicar al grupo)
```
"Ahora vamos a enviar un email simulado. Algunos de ustedes lo recibirán.
⚠️ ADVERTENCIA: NO HAGAN CLIC EN ENLACES NI ENTREN CREDENCIALES
⚠️ Esto es una SIMULACIÓN EDUCATIVA autorizada
Si lo abren, simplemente observen y repórtenlo como sospechoso"
```

### Mientras se Envía
```
1. Mostrar el email siendo redactado en pantalla
2. Leer el contenido en voz alta
3. Señalar elementos sospechosos
4. Enviar
5. Dar tiempo para que llegue (30 segundos - 2 minutos)
```

### Después de la Recepción
```
1. Pedir que levanten la mano quiénes lo recibieron
2. Mostrar en proyector cómo se ve
3. Analizar línea por línea
4. Hacer preguntas: "¿Qué les parece sospechoso?"
5. Revelar todos los indicadores
```

## 🔗 DEMOSTRACIÓN DE PÁGINA FALSA

### Antes de Mostrar
```
"Ahora vamos a mostrar a dónde llevaría el enlace malicioso.
Esto es una CAPTURA DE PANTALLA de un sitio fake.
En la realidad, alguien podría ingresar sus credenciales aquí."
```

### Cómo Mostrar
```
1. Abrir archivo fake-login-page.html en navegador
2. Proyectar en pantalla
3. Señalar indicadores de falsedad:
   - URL sospechosa
   - Logo copiado
   - Diseño genérico
   - Falta de certificado HTTPS
4. Tomar captura de pantalla
5. CERRAR SIN INGRESAR DATOS
```
